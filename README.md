# StackGen3D project page

Project page for **StackGen3D: Stable 3D Block Stack Generation from Multiview Silhouettes**
(Creativity in Assembly Workshop @ IROS 2026).

Live at <https://ripl.github.io/StackGen3D-web/>. Paper: <https://arxiv.org/abs/2610.31803>.

Plain HTML/CSS/JS, no build step:

- `index.html`: all page content
- `assets/css/style.css`: layout and styling
- `assets/js/main.js`: equation rendering (KaTeX), video controls, BibTeX copy button, section nav
- `assets/img/`, `assets/video/`: figures and videos

Preview locally:

```bash
python3 -m http.server 8000
```
